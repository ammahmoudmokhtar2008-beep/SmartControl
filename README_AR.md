# Smart Control — Android 0.2.0

تطبيق أندرويد للتحكم في الهاتف بالأوامر الصوتية العربية وإشارات اليد.

## التحكم الصوتي
اضغط «ابدأ الاستماع» وقل أمرًا مثل:
- ارجع / رجوع
- الرئيسية
- افتح الإشعارات
- افتح الإعدادات
- افتح واتساب
- افتح الكاميرا
- ارفع الصوت / اخفض الصوت / اكتم الصوت
- مرر لفوق / مرر لتحت

## التحكم بإشارات اليد
1. فعّل خدمة Smart Control من إعدادات إمكانية الوصول.
2. امنح التطبيق صلاحية الكاميرا.
3. اضغط «تشغيل التحكم بإشارات اليد». سيظهر إشعار دائم أثناء تشغيل الكاميرا.
4. يمكن الانتقال إلى تطبيق آخر مع استمرار خدمة الكاميرا إذا سمح إصدار أندرويد وسياسة الجهاز بذلك.

الإشارات:
- كف مفتوح: الشاشة الرئيسية.
- قبضة اليد: رجوع.
- الإبهام لأعلى: رفع الصوت.
- الإبهام لأسفل: خفض الصوت.
- تحريك اليد أفقيًا: تمرير أفقي.

## البناء
GitHub Actions ينزّل نموذج MediaPipe ثم يبني نسخة Debug ويرفعها كـ Artifact باسم SmartControl-debug-apk.

## ملاحظات
- يتطلب Android 8.0 أو أحدث.
- يحتاج التحكم العام إلى تفعيل خدمة إمكانية الوصول يدويًا.
- وضع الإشارات يحتاج صلاحية الكاميرا وإشعارًا دائمًا لأنه يعمل كخدمة أمامية من نوع Camera.
- قد تمنع بعض الشركات المصنّعة استمرار الكاميرا في الخلفية أو تقيّد الخدمات لتوفير البطارية.
- التعرف الصوتي العربي يعتمد على خدمة الكلام المثبتة في الهاتف وقد يحتاج اتصال إنترنت.
- هذه نسخة تجريبية غير موقعة بمفتاح إصدار للنشر. يجب اختبارها على أجهزة فعلية قبل اعتبارها إصدارًا نهائيًا.
